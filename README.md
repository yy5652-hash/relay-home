# Relay Home media

The demo film of Relay Home 2.3 and its captions. The source of the project is on the `main` branch;
`docs/demo-video.md` there says how the film was recorded and reproduces every line in it.

- `Relay_Home_Demo.mp4` (2:21, 1920x1080)
- `Relay_Home_Demo.srt`

The agent in the recording is Gemini 3.5 Flash-Lite. Waits for the model are shortened.

Live action: stock footage from Mixkit under the Mixkit Stock Video Free License (hourglass 28901, subway platform 1622, dominoes 5246, hand and phone 144).
Voices: synthetic (Kokoro, Apache-2.0): a narrator, the person, and Relay, which says the text its own page asked to be spoken. Music and sound: synthesised for this film.
